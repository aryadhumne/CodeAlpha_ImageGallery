# CodeAlpha_ImageGallery

A responsive image gallery built with pure HTML, CSS, and JavaScript — Task 1 of the CodeAlpha Frontend Development Internship.

## Features
- 🖼 Masonry-style CSS Grid layout with tall & wide cards
- 🔍 Lightbox viewer with full-resolution images
- ⬅ ➡ Prev / Next navigation (buttons + keyboard arrows + touch swipe)
- 🏷 Category filter (Nature, Architecture, People, Abstract, Travel)
- ✨ Smooth hover effects, staggered fade-in animations
- 📱 Fully responsive (mobile, tablet, desktop)
- ⌨ Keyboard accessible (Esc to close, Arrow keys to navigate)

## Tech Stack
HTML5 · CSS3 · Vanilla JavaScript · Unsplash (image source)

## How to Run
Simply open `index.html` in any browser. No build step required.
